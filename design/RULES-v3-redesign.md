## 一、診斷(引用準則原則/病灶)

### D1【致命】核心幻想失靈 — 68% 的局以「比誰有錢」收場
Knizia:「勝利條件定義整個遊戲」。本作的玩家幻想是**科技冷戰**,但 68% 的局數雙方都沒達成門檻,
落入 fallback 的「資本最多者商業勝利」——玩家實際在玩的遊戲是囤資源,不是冷戰。
這同時解釋了 D5(長期策略吃虧:囤錢比蓋引擎划算)與 D3(日韓躺贏:終局型態太常見)。

### D2【嚴重】滾雪球 — 收益紅利與陣營領先掛鉤
病灶診斷表「滾雪球」:收益紅利 = 陣營科技力÷100,米國開局 200 點即享 +2,牆國只有 +1;
領先→更富→更領先。4 人局米國冠軍率 55%,米國個別角色冠軍率約為牆國角色的 **2 倍**。
(註:「米國優勢=高初始科技力→高收益」是使用者確認的設計,本提案不取消,只溫和制衡。)

### D3【嚴重】日韓攪局者躺贏 — 被動門檻 × 高發生率
8 人局日韓冠軍率 19~21%(基線 12.5%)。Ruhnke/Wehrle 原則:「每個陣營的勝利條件都要能**主動推進**,
不能只是等別人失敗」。平均終局科技差 116 點(5.8 年)恰好落在日本勝利區間,日本什麼都不做就常贏。

### D4【嚴重】台灣無代理權 — 押寶是擲硬幣不是決策
`twSupport = Math.random()`:台灣的勝利條件「押對寶」在**開局就被系統隨機決定**。
病灶「純賭運」:關鍵秘密應是玩家選擇。台灣的玩家幻想是「造王者的權力感」,現在卻是彩券。

### D5【中】長期策略被懲罰 — 引擎構築不回本
短期 1.22 vs 長期 0.85。三幕劇弧線壞掉:12 季 × 建造冷卻 1 年 × 高階卡指數費用,
引擎回收期超過剩餘局長;商業勝利又直接獎勵囤資源。預期 D1 修正後大幅自癒,修完重測。

### D6【低】角色能力強弱差過大
交通 perk(免費移動)與硬體 perk(研發-3)每回合必發動;媒體 perk(假新聞免費)情境太窄。
馬化疼在兩種人數下都墊底(4.2% / 2.3%)。

### D7【低】規則贅肉
每回合 7 個 once-per-turn 旗標(playedTech/playedOps/moved/forfeit×3/exchanged)+ 三套資源調節系統
(兌換/放棄/交易環節)。放棄權利制是使用者確認語意,保留;但 `opsHit`「每張卡終生只能被竊取一次」
是永久狀態的記憶負擔,建議改時間制。

### D8【觀察】先攻者反而吃虧
第 1 位行動冠軍率 22.2%(均值 25%)。輕微,暫不處理,列入每次 A/B 報表觀察。

## 二、處方

### P0 — 已套用(config-only,模擬驗證通過)

**techStart.CN:100 → 110**(米牆科技差 90 點開局)

| 指標 | v2 基準 | CN=110 |
|---|---|---|
| 米國門檻勝 / 牆國門檻勝 | 20.5% / 11.5% | **17.5% / 16.5%** |
| 米/牆/台 冠軍率 | 55.0 / 26.2 / 18.8 | **49.0 / 30.8 / 20.2** |

劇情解釋不變:差距仍存在(4.5 年),米國優勢(高科技力收益)完整保留,只是把終點線拉公平。
殘餘的米國冠軍率優勢(+18pp)主要來自 D1 商業勝利偏好高收益方,待 P1-1 修正。

### P1 — 建議實作(需改 code,附規格)

#### P1-1 終局判定改革(修 D1、D3)— `server/game.js` `endGameByRounds()`
打滿 12 季時**必分陣營勝負**,商業勝利退場為極端例外:

| 終局科技差(US−CN) | 結果 |
|---|---|
| ≥ +5 年(100 點) | **米陣營終局勝**(米國玩家 + 日本同列贏家) |
| ≤ −5 年 | **牆陣營終局勝**(牆國玩家 + 韓國同列贏家)※韓國條件見 P1-3 |
| 中間(冷戰僵局) | **韓國獨勝**(達成 P1-3 條件時);無韓國或未達成 → 商業勝利 |

- 台灣依秘密立場跟隨陣營終局勝。
- 多位贏家中冠軍仍由資本決定——保留「陣營合作 × 個人私利」雙層張力(這是本作最好的設計,強化而非移除)。
- 提前門檻勝(±10年/追平)規則不變。
- 效果:每一局的勝負都回到科技軌道;最後 2~3 季從垃圾時間變成「把 lead 推進/推出 ±5 年帶」的衝刺(原則 5:終局衝刺感)。

#### P1-2 台灣自選立場 + 一次轉向(修 D4)— `server/game.js` 建構子 + 新行動
- 開局由台灣**玩家秘密自選**支持方(AI 仍隨機);UI 在選角後、遊戲開始前詢問(PIN 裝置)。
- 新增台灣專屬行動「**轉向**」(1 AP,未表態前限一次):秘密改變支持方,神山儲備減半(情報外洩的代價)。
- 效果:押寶從彩券變成讀盤決策;轉向讓台灣中盤仍能回應局勢(Wehrle:政治即玩法)。

#### P1-3 日韓勝利主動化(修 D3)— `server/game.js` `endGameByRounds()` + config 新參數
- 日本終局分享米陣營勝 / 韓國分享牆陣營勝或僵局獨勝,皆需**自身場上 ≥ 3 張科技卡**(`config: spoilerWinCards: 3`)。
- 效果:攪局者必須下場蓋引擎(可被間諜卡拆=可被反制),「躺贏」消失;
  日韓的科技力本來就計入米/牆,蓋卡同時是在推自己想要的 lead 區間——目標、手段、計量自洽(COIN 原則)。

#### P1-4 收益紅利封頂(修 D2 殘餘)— `techBonusOf()` + config 新參數
`techBonus = min(techBonusCap, floor(本國科技力/100))`,`techBonusCap: 3`。
保留米國「科技力=收益」優勢的方向,砍掉後期無限滾雪球的尾巴。

#### P1-5 角色 perk 微調(修 D6)— `public/js/data.js`
- 媒體 perk(渣克伯/馬化疼):假新聞免費 **+ 打出假新聞時抽一張卡**(讓窄 perk 有泛用補償)。
- 交通 perk(馬一龍/馬已今服):免費移動限**相鄰**(現況已是)且每回合一次(現況已是)——暫不削,先觀察 P1-1 後分布。
- 改動後跑 `--seats` 固定陣容模擬確認極差 < 2 倍。

### P2 — 可選(playtest 後決定)

1. **opsHit 改時間制**(修 D7):「終生一次」→「每年一次」(記 round,類比 builtRound)。
2. **長期軸再平衡**(修 D5):P1-1 上線後重測;若長期比仍 < 0.95,候選依序:
   `cityBuildCooldown 4→3`、5 階卡 trade 產出 +2、`forfeitBase 3→2`(壓縮囤資源報酬)。
3. **RULES.md 重寫**:現行 RULES.md 仍描述 v1(單一資本、10 輪、3 行動點研發翻牌制),
   與 v2 實作嚴重脫節,待 P1 定案後一次重寫,並把「玩家幻想」寫進各陣營介紹(教學即代入)。
4. **交易環節觀察**:每季全員交易是否拖節奏(下檔時間原則)?實體 playtest 計時;若拖,改每年(Q4)一次。

## 三、驗證計畫

每個 P1 項目獨立分支驗證,指令:
```
node test/simulator.js --games 1000 --players 4 --quiet   # 4人
node test/simulator.js --games 1000 --players 8 --quiet   # 8人(日韓)
node test/simulator.js --games 600 --players 3 --quiet    # 3人(最小局)
```
驗收標準:
- 打滿 12 季比例 < 40%,且其中商業勝利 < 5%(P1-1)
- 同人數同陣營人數下,米/牆門檻勝率各在 40~60% 帶(P0 已達成)
- 日韓冠軍率 10~16%(P1-3)
- 短期/長期策略勝率比皆在 0.95~1.15(P2-2)
- 角色冠軍率極差 < 2 倍(P1-5)
- 各座位冠軍率差 < 5pp(D8 觀察)

實作時注意:`server/bot.js` 策略六軸需同步教會 AI 新行動(台灣轉向、日韓蓋卡需求),
否則模擬數據會低估新規則的真實強度。
